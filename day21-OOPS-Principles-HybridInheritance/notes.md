# Day 21 — Hybrid Inheritance

## What is Hybrid Inheritance?

Theory:

- > Hybrid Inheritance is a combination of two or more types of inheritance
- > In Day 21 example: combination of Multiple Inheritance + Single Level Inheritance
- > NOT supported with classes — supported through interfaces

## Structure:

Interface A      Interface B
     ↘               ↙        ← Multiple Inheritance
         Class C
             ↓                ← Single Level Inheritance
         Class D
