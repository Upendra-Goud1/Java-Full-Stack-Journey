# OOPS Principles

## 3) Encapsulation (3rd OOP Principle)

Theory:

- > Encapsulation is nothing but hiding something
- > Use encapsulation by making your variables private
- > Hide your variables in Java from accessing to other classes — so we have to make variables private
- > By the help of getters and setters we can access variables in other classes
- > Which access modifier we use for getters and setters? → public — so we can access across the project
- > By using getters and setters only, we will print private variables in another class

## Why use a setter?

- > To update the value
- > To stop unwanted values from being set
- > You can write conditions inside setters so that no one can pass wrong values to that variable

## Why use a getter?

- > Getters are used to see (get) the value
- > Controlled read access to private variables from outside the class
