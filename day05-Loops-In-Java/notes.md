# Day 5 — Loops in Java


## 1) For Loop (Entry Controlled Loop)

Use when you know exactly how many times to repeat a task.

## 2) While Loop (Entry Controlled Loop)

Use when you don't know how many times to repeat — condition is checked before each iteration.

## 3) Do-While Loop (Exit Controlled Loop)

Executes the body at least once, even if the condition is false (condition is checked after execution).

## 4) Nested For Loop

One for loop inside another for loop — used for patterns, matrices, and multi-dimensional iterations.

## 5) Break Statement

Exits the current loop immediately — skips all remaining iterations.

## 6) Continue Statement

Skips the current iteration and jumps to the next iteration.

## 7) Labels (Break Outer/Inner)

Use labels to break out of nested loops — specify which loop to break.

Break Outer Loop: it will break outer loop 

Inner loop : it will break inner loop .
