# Day 25 — Mini Project: Driver Travel Management System

## Project Overview

- > A Java mini project that applies all OOP concepts learned so far — POJO, encapsulation, arrays, methods, Has-A relationship — in a real-world Driver Travel Management System.

## Concepts applied:

- > POJO (Plain Old Java Object)
- > Encapsulation (private fields + getters/setters)
- > Arrays
- > Methods with business logic
- > toString() override
- > for-each loop
- > Has-A relationship (Travel uses Driver)
